# 同题双问训练数据

对照臂使用已冻结的 `nine-data/train.jsonl`。干预臂使用同序的 `paired.jsonl`。两臂每轮都有 9,000 行，均包含 634,005 个提示 token 和 1,353,439 个监督 token。监督范围包括回答正文及一个原生 EOS（151643）。每条完整序列不超过 384 token，按原文完整编码。两臂共用原来的 120 条验证样本。

## 怎样形成一对

每个核心题保留原始来源 ID、题干和一个原版答案。围绕同一题干添加两种交付要求，分别只给结果、给结果并交代理由或可核查依据。原训练集的一条记录保留在原行，另一条同季度记录让出位置给配对版本。让出位置的行仍沿用原调度 ID，实际内容来源见 `source_id`。逐对映射、原始来源、让出行 ID、两行角色和核验依据均在 `pairs.jsonl`。依 `source_file` 与从 1 开始的 `source_line` 可在魔搭 COIG-CQIA 固定版本中定位原文。

- 单选题使用来源解析末尾明确选择的字母，核对四个选项的顺序和所选项文本，保留原解析。较短版本按指令给字母、选项原文或字母加原文。
- 古今互译保留来源译文。解释给出原文与译文的一个真实用词对应或专名保留情况。分词和实体题用原文位置、片段数或字符区间核验。
- 日期使用日历运算独立验证。四则运算使用有理数重新计算，拒绝无法确认的算式。错字题核实替换前后的字符并针对语境说明修改。

共有 1,095 对、2,190 条改写记录，另有 6,810 条整行保持原样。干预臂涉及 7,905 个不同的原始内容 ID，1,095 个核心题各出现两次。913 对为单选题。被替换的 1,095 条中有 728 条原属中文文本任务、157 条原属财经文本。实验同时改变部分题目的来源分布、题目重复次数和回答形式。评测的差异应解释为这套完整配方的结果。913 道单选保留了来源的学科和历史考试判断，语义核验方法是选项与原解析对照加分层抽阅。

## 预算和排重

先按第一轮季度，在相同监督长度的实样本中用整数匹配选择位置，使两臂提示总数相同，再在同一监督长度及第一轮季度内交换配对位置，使第二轮各季度也完全平衡。每一个原行 ID 的监督 token 数保持相同。每个优化步骤使用相同的原行 ID，所以监督分母也相同。每个实际季度的非 padding 提示、监督及合计均在 `audit.json`。各微批的真实提示长度和运行时间仍可不同。

对 60 个新评测核心题，审计比较了两份训练数据与固定验证集的题干、回答。Unicode 归一后的文本全等、完整题干子串、连续 16 个字符或较高四元字符组覆盖率均未触发。词面审计范围和阈值见 `audit.json`。

## 复现

在此实验的 work 目录结构中，安装 Python 的 `tokenizers` 包并准备同一份 Qwen2.5-7B tokenizer、冻结原始 9,000 条数据及训练调度文件。可使用冻结配对映射重建到另一个目录并逐字节比较。此途径无需 GPU 或求解器。

```sh
python work/pair-data/build.py --selection work/pair-data/pairs.jsonl --output-dir /tmp/qwen-pair-rebuild
cmp /tmp/qwen-pair-rebuild/paired.jsonl work/pair-data/paired.jsonl
cmp /tmp/qwen-pair-rebuild/pairs.jsonl work/pair-data/pairs.jsonl
python work/pair-data/audit.py
```

重新搜索槽位时可以省略 `--selection`，并为 `--solver-python` 指定含 SciPy HiGHS 整数求解器的解释器。不同求解器版本可能选到另一组同样满足预算的匹配。实际训练文件 SHA-256 为 `911843fd787d5366efc63fd73af290ca40f37cc12da6365ccca898b34afc6965`。
