# 同题双问，预注册评价约定

60道新编中文核心题，十个领域。每个领域向开发和独立确认各分3道；每份30道含10道带A/B/C/D选项的选择、20道须自行生成的答复。少量自填题的答案范围有限，如“符合”一词。每道题的题干、选项、数值完全相同，只改变最后的作答要求。每题独立推理两次，一次只要最终答案，一次要求结合具体条件给答案和理由。参考结果及所需理由在 items.jsonl，原始草稿在 core.tsv。题目覆盖数量、统计、流程、程序、科学、逻辑、阅读、语义、空间和规则。选择题的正确字母在全集均衡。源码可复建提示与分组。

主比较锁定两个训练组第2轮的独立确认集，分别为 paired 与 control。主要指标为同一个核心题两种问法均通过：短答结论正确且准确遵守短答形式，解释版结论正确且理由充分正确。为保持解释形式自由，解释版未要求编号、句数、结论位置或特定关键词；理由真实、正确、足够说明结论比篇幅更重要。报告按核心题配对的改善/变差数、双侧精确 McNemar 检验和配对题目重抽的百分点差95%区间。另列第1轮及整个轨迹。两个训练组各自在30道开发题上选配对通过率最高的检查点，并列选较早者；再在30道独立确认题上描述复核。同一核心题的两个答案不可拆作两个独立样本。多数次要比较属于描述性观察。

短答内容与形式分开。选错的单个大写字母可以过形式；核心值正确但附理由、代码围栏、标签、复读题干或多余的问答，不能过严格短答形式。按题目声明的答案形状检测。去首尾空白；裸数、字母、分数、时间、坐标等纯输出不允许额外标点。自然中文词或人名允许一个句末句号，其边界不改变答案，额外前缀或解释仍不合格。允许等价同义表达、等价数学值作为内容正确；如果要求阿拉伯数或最简式但没遵守，只影响形式。选择题在解释版允许以正确字母或对应选项内容明确表达选择。复述数个选项而未作选择不算正确。短版只报告选项文字而未按要求给字母，可内容正确而形式失败。唯一且明确的答案后再续写无关材料，仍可得内容分；同一问题给出互相冲突的确定结论时，结果分为0。

理由分按每题预先写定的必要事实、规则或有效推导来给，允许等价解释。算术接受能导出结论的正确算式，逻辑接受证成结果的有效推理，阅读接受能直接支持答案的题内证据，程序接受等价执行轨迹。仅把结论换句话重复、泛称“根据题意”、仅复读问题，均不足。理由与结论是两个字段；正确结论背后的错误因果使理由得0。独立记录是否有实质解释尝试，即使理由错误；“理由缺失”指没有尝试，“理由不充分或错误”取所有未通过理由项。短答“过度解释”指确实增加原理、推导、引文或用于证明的代码，而非把一切格式错误都称为过度解释。JSON围栏、末尾标点、单位及纯标签本身不单独算解释。解释版额外的前缀、换行或正确证成后追加无关材料，在不推翻原理由时，不因风格单独扣分；虚构更改条件或自相矛盾的论证不能得理由分。有效结论或理由在输出上限前已完整出现则按原文算分；另记停止原因。空答案在内容、短格式、理由均为0。

先把生成文本按题号、S/R及原文去重，打乱并用与模型名无关的标识，阶段映射在评阅后合并。形式自然且答案为冻结参考的简单短答可自动通过；其他短答结合语义核对，多义形式由评阅者按题逐条核查。解释版逐条审核或用可精确辨别的封闭规则判分，并保留匿名判断。评阅者是Codex，无独立人类专家打分；计数只代表本题库。长度差按同一题解释版减短答版的正文生成token，不含停止符。推理程序对两种问法和各检查点使用相同模板、贪心策略和256个新token上限。
