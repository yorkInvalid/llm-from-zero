④ 一次前向，预测两个位置
输入形状 [2, 53]。28 层因果 Transformer 输出 [2, 53, 3584]。位置 40 看完提示，预测位置 41 的 C；位置 41 看到了正确的 C，预测位置 42 的结束符。因果遮罩挡住未来的答案。
⑤ 只给回答打分
提示和补齐位置不直接计分。这个微批取 33 个预测位置，经 lm_head 得到 [33, 152064] 个分数。本题贡献两项：−log P(C｜提示) 与 −log P(结束｜提示,C)。
⑥ 反传并更新 LoRA
4 条样本分成 2 个微批。每个微批的交叉熵之和除以整步 468 个监督 token，再反传、累积梯度。AdamW 更新 LoRA 的 A、B 矩阵；原始底座权重冻结。

云端第 3 步实测　1204.5901 ÷ 468 = 2.57391（4 条合计的平均 loss）。学习率 6.667e-06，裁剪前梯度范数 0.92049，低于阈值 1。共有 20,185,088 个可训练参数。日志没有保存这条样本单独的概率、loss 或权重改变量。

 93  def active_logits(model, group, pad):
 94      width = max(len(r['ids']) for r in group)
 95      inputs = torch.tensor([r['ids'] + [pad] * (width-len(r['ids'])) for r in group], device='cuda')
 96      idx = torch.arange(width, device='cuda').unsqueeze(0)
 97      ends = torch.tensor([len(r['ids']) for r in group], device='cuda').unsqueeze(1)
 98      starts = torch.tensor([r['split'] for r in group], device='cuda').unsqueeze(1)
 99      mask = idx < ends
100      target_mask = ((idx >= starts) & mask)[:, 1:]
101      network = model.get_base_model()
102      hidden = network.model(input_ids=inputs, attention_mask=mask.long(), use_cache=False).last_hidden_state
103      target_values = inputs[:, 1:][target_mask]
104      return network.lm_head(hidden[:, :-1][target_mask]).float(), target_values
