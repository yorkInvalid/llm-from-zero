# 第二课 · 位置编码如何进入 attention

审阅草稿 v5。当前完成教学目标、计算例子、六阶段教学分镜。每个阶段对应同一张画布上的一次推进。

## 一、教学目标

贯穿全课的问题是“同一个 token 换了位置，计算怎样感知这个变化？”

观众已经学过 X → Q/K/V → 点积 → 缩放 → softmax → 加权求和。本课在这条熟悉的流程里加入位置信息。

本课通过问题、解释和逐步推导，讲清下面四件事。

1. 用交换两个输入的例子，说明无位置编码、无位置相关 mask 的 attention 如何随输入重排。
2. 给定位置编号和维度，算出一对 sin/cos 数值，并指出它们加到输入的哪里。
3. 对 Q、K 中的一对数完成旋转，解释点积里为什么会出现位置差。
4. 在完整流程中指出 Sinusoidal 和 RoPE 的作用位置，追踪它们怎样影响注意力权重。

### 讲解者逐一提出并解答的问题

- 把“我”和“你”调换位置，内容向量、位置编号分别怎样变化？
- 第三个 token 的位置编号为什么是 2？
- 位置编号是 0 时，sin/cos 编码是多少？
- Q、K 同时旋转相同角度，点积怎样变化？
- RoPE 的旋转角度由什么确定？投影矩阵由什么更新？

本课使用固定公式产生位置编码。训练更新投影矩阵等模型参数，使模型学会利用这些位置信息。

## 二、例子与计算约定

### 2.1 两句始终可见的话

画布开场显示“我 / 想 / 你”和“你 / 想 / 我”。每个词块下显示位置编号 0、1、2。词块的颜色跟随词移动，位置编号固定在槽位上。

这三个词块采用教学用分词。进入数值演示后，显示“固定随机向量演示”，使用第一课的三个 10 维向量。演示中的词标签用于帮助追踪身份，数值来自第一课固定数据。

### 两句话的实际对照与画面表达

固定“我”“想”“你”的内容向量为第一课 x₁、x₂、x₃。交换句子时交换第 0、2 列，位置编号仍为 0、1、2。两句都跟踪中间“想”的 query，采用全部位置可见，并按词身份对齐结果。

| 编码 | 句子 | “想”分给“我”的权重 | “想”输出第 0 维 |
|---|---|---:|---:|
| 无 | 我想你 | 31.3055% | -0.545066 |
| 无 | 你想我 | 31.3055% | -0.545066 |
| sin/cos | 我想你 | 30.4375% | -0.679362 |
| sin/cos | 你想我 | 29.5978% | -0.677178 |
| RoPE | 我想你 | 29.5526% | -0.541446 |
| RoPE | 你想我 | 32.6815% | -0.551148 |

“想”输出第 0 维指输出向量 b 的第一个分量。若“想”对三个 token 的权重为 α₁、α₂、α₃，则 b[0]=α₁v₁[0]+α₂v₂[0]+α₃v₃[0]。它的数值由权重和三个 value 的该维分量共同决定，正负和大小取决于当前表示坐标。当前随机模型中，这一维没有预先指定的语义标签；从 -0.545066 无法推断想念的程度或模型理解程度。

该列用于展开计算时核对结果。画布主视图优先展示按词身份对齐的注意力权重，并在展开输出时展示五维向量及其变化。“输出变化”支持位置影响计算这一结论，语义理解效果需要任务评估。

上述结果已用现有代码计算。画面并列展示两句，锁定“想”，用相同坐标范围的三根权重条展示它分给“我”“想”“你”的权重。交换时，按词身份对齐条形，避免把排列变化误读成权重变化。旁边展示五维输出逐项差值，并标出最大绝对差。

当前随机参数下，sin/cos 的变化较小。配合数字差值和高亮帮助观察，所有对照使用同一纵轴比例。观众应得到的直观结论是“交换顺序后，位置参与计算使同一个词的表示产生变化”。这些随机向量上的差异能验证位置机制；“谁想谁”的语义识别效果需要带标签的任务、训练和独立测试来评估。

### 方法的引入顺序

先从“内容怎样带上位置”引入原始 Transformer 的具体选择，再逐步构造公式。

> “2017 年的 Transformer 论文使用过一种明确的构造方法。给每个位置生成一个与词向量同维度的位置向量，里面交替放入 sin 和 cos 的计算结果，再把它加到输入上。我们先亲手算出这个位置向量，看看它怎么让位置进入 attention。”

画布在阶段二讨论整数方案后显示“原始 Transformer · 2017 · Sinusoidal”，随后展开位置向量。原论文也实验过可学习的位置嵌入，课程这里沿着固定 sin/cos 方案讲解。[Transformer 原论文 §3.5](https://arxiv.org/html/1706.03762v7)

完成 sin/cos 的整条计算后，再引入目前广泛使用的 RoPE。

> “接下来学习现在很多大语言模型采用的旋转位置编码，简称 RoPE。例如 Qwen3 使用了这种方法。我们已经知道 attention 通过 Q 和 K 的点积计算分数。能不能直接让这个点积带上两个 token 的位置关系？RoPE 通过按位置旋转 Q 和 K 来实现。下面从两个坐标的旋转开始看。”

画布在阶段五入口显示“RoPE · 旋转位置编码”，点亮 Q、K 与点积之间的连接。参考 RoFormer 提出的构造，以及 Qwen3 的官方实现。[RoFormer](https://arxiv.org/html/2104.09864v5)、[Qwen3 实现](https://github.com/huggingface/transformers/blob/main/src/transformers/models/qwen3/modeling_qwen3.py)

### 2.2 数据来源与符号

直接读取第一课 `dist/data.json` 的 X、WQ、WK、WV，使用第一个注意力头，固定参数做前向计算。

| 符号 | 含义 | 形状或约定 |
|---|---|---|
| X | 三个 token 的内容向量，按列放置 | 10 × 3 |
| x₁、x₂、x₃ | 第一、第二、第三个 token 的向量 | 各 10 维 |
| p | 从 0 开始的位置编号 | 0、1、2 |
| P | sin/cos 位置编码矩阵 | 10 × 3 |
| Z = X + P | 加入位置后的输入 | 10 × 3 |
| Q、K、V | 一个头的投影结果 | 各 5 × 3 |
| A | 缩放后的分数矩阵 | 3 × 3，行 key、列 query |
| A′ | 沿每列 softmax 的注意力权重 | 3 × 3 |
| B = VA′ | 当前头的输出 | 5 × 3 |

主线继续追踪 q₃ 和 b₃。维度从 0 编号，token 名称沿用第一课从 1 编号，因此 x₃ 对应 p = 2。

开场的全序列重排实验使用双向可见。画布明确显示“全部位置可见”。回到预测下一个 token 的流程时使用因果 mask，并标出每个 query 可见的 key。第三个位置可以看到这三个输入，因此这一列的权重与双向可见时相同。

第一课的因果 mask 已经通过可见范围引入顺序约束。开场重排结论适用于这里明确设置的双向可见实验。多层因果模型还能通过可见范围间接利用顺序信息。

### 2.3 Sinusoidal 的可复算例子

每一对维度使用同一个频率，角度单位为弧度。

\[
\omega_i=10000^{-2i/10},\quad
P_{2i,p}=\sin(p\omega_i),\quad
P_{2i+1,p}=\cos(p\omega_i)
\]

i = 0、1、2、3、4 对应五对维度。五个频率约为 1、0.158489、0.025119、0.003981、0.000631。

重点展开第三个 token，即 p = 2。

| 维度对 | 频率 | 角度 | sin | cos |
|---|---:|---:|---:|---:|
| 0、1 | 1 | 2 | 0.909297 | -0.416147 |
| 2、3 | 0.158489 | 0.316979 | 0.311697 | 0.950181 |

第一课 x₃ 的前两维为 0.900717、-1.234545。相加后为 1.810015、-1.650692。

**这个例子要让观众观察什么？**

这一步演示位置编号怎样通过确定的公式进入输入向量。只列出一次相加，能够检查算术过程；要展示位置的作用，需要固定同一个内容向量，再改变它的位置。

| 固定同一个 x₃ | 位置编码前两维 | 相加后的前两维 |
|---|---|---|
| 放在位置 0 | (0, 1) | (0.900717, -0.234545) |
| 放在位置 2 | (0.909297, -0.416147) | (1.810015, -1.650692) |

画布让同一个内容向量在位置 0、2 之间移动，高亮这两行的变化。讲解者随画面给出结论“内容相同，位置不同，送入投影的表示随位置改变”。随后沿 Q/K、点积、softmax 追踪到注意力权重，观察这种变化怎样影响计算。

这里每个数都是向量在某个维度上的分量。sin/cos 的分量由位置和频率确定，数值较大不能据此判断某对维度更重要。维度对的频率决定该对坐标随位置变化的速度。模型通过训练学习如何利用这些分量。


**为什么需要多种变化速度？**

先提出问题“同样是描述位置，一对 sin/cos 已经有两个数，为什么还要更多对？”

对第 i 对维度，记 eᵢ(p)=(sin(pωᵢ),cos(pωᵢ))。位置每前进 Δ，角度增加 Δωᵢ。频率较高时，相同位移带来较大的角度变化；频率较低时，绕一圈需要更长的位置跨度。正弦分量本身在不同角度处的变化快慢也会不同，这里说的速度指角度随位置的增长速度。

只用一对时，周期性会让相隔较远的位置得到相近的坐标。组合多对频率后，观众可以同时观察多个周期尺度的变化，为模型提供更丰富的位置特征。

进一步提出问题“这些数与两个位置的关系有什么联系？”画布逐步展开一对位置向量的点积。

\[
 e_i(p)^T e_i(r)
 =\sin(p\omega_i)\sin(r\omega_i)+\cos(p\omega_i)\cos(r\omega_i)
 =\cos((p-r)\omega_i).
\]

利用 cos(a−b)=cos(a)cos(b)+sin(a)sin(b)，可以看出该结果由位置差和频率共同决定。固定距离差为 1 时，频率 1 给出 cos(1)≈0.5403，频率 0.01 给出 cos(0.01)≈0.99995。这是独立的两频率几何辅助例子，主算例仍使用上表的五个频率。

讲解者给出答案“每个频率用自己的周期描述位置差，把多对组合起来，就提供了多个变化尺度的位置特征”。这个点积随位置差周期变化，数值大小不能直接解释为语言关系的重要程度。

上式描述纯位置编码向量的点积。实际 sin/cos 路径先相加、再投影，分数为 (xₘ+Pₘ)ᵀWqᵀWk(xₙ+Pₙ)，其中同时包含内容、位置及其交互。后续讲解沿真实计算路径展示它们怎样共同影响权重。

不同频率使不同维度随位置以不同速度变化。10000 是这套公式选定的基数，决定频率范围。完整 10 维编码可展开查看。[Transformer 原论文 §3.5](https://arxiv.org/html/1706.03762v7)

### 2.4 RoPE 的可复算例子

沿用现有实现，每头 5 维中的前 4 维参与旋转，最后 1 维保留。参与旋转的两对维度为 (0,1)、(2,3)，频率按旋转维度 4 计算，分别为 1、0.01。这是当前项目的 partial RoPE 约定。

\[
R(\theta)\begin{bmatrix}u\\v\end{bmatrix}
=\begin{bmatrix}u\cos\theta-v\sin\theta\\u\sin\theta+v\cos\theta\end{bmatrix},
\quad \theta=p\omega_i
\]

q₃ 的前两维 (-0.084226, -0.274866) 在位置 2 旋转 2 弧度，得到 (0.284985, 0.037798)。第 2、3 维旋转 0.02 弧度。最后一维为 -0.063134。

**这个例子要让观众观察什么？**

这组坐标演示旋转怎样计算。画布需要同时画出原向量和旋转后的向量，让观众看到角度改变、长度保持。单独观察一个 q 的坐标，还不足以解释位置关系怎样进入注意力。

接着同时展示固定内容的 q、k，分别按各自位置旋转，并观察它们之间的夹角及点积。一个容易手算的二维辅助例子是 q=k=(1,0)，频率为 1。此例在画布单独标注“二维几何示例”。

| query 位置 m | key 位置 n | 位置差 n−m | 旋转后点积 |
|---:|---:|---:|---:|
| 0 | 0 | 0 | cos(0)=1 |
| 0 | 1 | 1 | cos(1)≈0.540302 |
| 3 | 4 | 1 | cos(1)≈0.540302 |

前两行让观众看到位置差能影响点积；后两行让观众看到共同平移保留位置差，因此点积保持。下面的旋转矩阵等式给出一般解释。这个例子选择了相同的单位向量，实际模型的点积还受 q、k 内容影响；距离与分数的关系会随内容和旋转角度变化。

每对坐标的乘积求和会贡献一部分点积分数。所有维度贡献相加、缩放，再对同一个 query 的各个 key 做 softmax，才能得到 token 之间的注意力权重。画布把旋转后的分量、点积分数、注意力权重依次标明，帮助观众理解它们各自的作用。


对同一二维分组，query 位于 m、key 位于 n 时，有

\[
\widetilde q_m^T\widetilde k_n
=q_m^T R(m\omega)^T R(n\omega)k_n
=q_m^T R((n-m)\omega)k_n.
\]

内容向量 q、k 和相对位置 n−m 共同参与这个分数。几何演示固定 q、k 的内容，只改变位置编号，便于观察位置因素。多对维度的点积相加，形成旋转部分的总分。[RoFormer 原论文 §3.2](https://arxiv.org/html/2104.09864v5)

### 2.5 三种计算的核对值

使用同一份 X 和投影参数，关注第三个 query。显示值保留 6 位小数，底层用完整精度计算。

| 方式 | 对 x₁ 的权重 | 对 x₂ 的权重 | 对 x₃ 的权重 | b₃ 第 0 维 |
|---|---:|---:|---:|---:|
| 无位置编码 | 0.296690 | 0.357477 | 0.345834 | -0.541949 |
| Sinusoidal | 0.286299 | 0.340239 | 0.373462 | -0.675748 |
| RoPE | 0.315634 | 0.348542 | 0.335824 | -0.547945 |

这些数字展示编码进入计算后的影响。预测质量需要训练与任务评估来判断。现有求平均训练任务的目标对输入重排保持一致，因此本课的验证聚焦前向计算与位置机制。

### 阶段三 · 这两个三角函数，究竟带来了什么？

本阶段按三个问题连续推进。每次只展开当前问题所需的公式和图形。

#### 3A · 先算一对数

| 步骤 | 口播草稿 | 画面、鼠标与推导 |
|---|---|---|

#### 3B · 怎么从一个位置，走到另一个位置？

| 步骤 | 口播草稿 | 画面、鼠标与推导 |
|---|---|---|
| 1 | “算出数以后，还有个问题。位置 p 往后走 k 格，新编码跟原编码有什么关系？” | 两个槽位 p、p+k 并列，中间画距离 k。 |
| 2 | “先把这一对的频率记成 ω。原来的角度是 pω，移动以后是 pω 加 kω。” | 保留频率定义于角落，主区域逐项展开 (p+k)ω=pω+kω。 |
| 3 | “这就能用到和角公式。sin 的新值，由原来的 sin 和 cos 各乘一个系数，再加起来。” | 先显示 sin(a+b) 恒等式，再逐项代入。原有 sin、cos 用固定两色，对应项同步高亮。 |
| 4 | “cos 也展开一遍。你看，两行里都有 kω。位置 p 可以变，这两个系数只跟移动了多少格有关。” | 完整展开 cos 的推导。圈出 cos(kω)、sin(kω)，p 项保持可见。 |
| 5 | “把两行排成矩阵，就是用同一个变换，把位置 p 的编码移到 p 加 k。这个规律可以在不同起点重复使用。” | 从两行标量式组成下面的矩阵。固定 k=1，演示 p=0 与 p=3 两组结果。 |

按本课 sin、cos 的分量顺序，推导写为

\[
\begin{aligned}
\sin((p+k)\omega)&=\sin(p\omega)\cos(k\omega)+\cos(p\omega)\sin(k\omega),\\
\cos((p+k)\omega)&=\cos(p\omega)\cos(k\omega)-\sin(p\omega)\sin(k\omega),\\
\begin{bmatrix}\sin((p+k)\omega)\\\cos((p+k)\omega)\end{bmatrix}
&=\begin{bmatrix}\cos(k\omega)&\sin(k\omega)\\-\sin(k\omega)&\cos(k\omega)\end{bmatrix}
\begin{bmatrix}\sin(p\omega)\\\cos(p\omega)\end{bmatrix}.
\end{aligned}
\]

这是位置编码之间的代数性质，为模型利用相对位置提供结构。实际 attention 参数如何利用它，由训练决定。[Transformer 原论文 §3.5](https://arxiv.org/html/1706.03762v7)

## 四、口播节奏与鼠标同步方案

### 口播的写法

- 用自然短句，每句话指向一个明确对象。例如“先看第三个 token。它的位置编号是二。”
- 把观众可能卡住的地方说出来，例如“这个数算出来了，然后呢？”紧接着展示推导并回答。
- 适量使用“你看”“先别急”“我们换个位置试试”，每个指示语都绑定画面对象。
- 公式展示完整符号，口播按含义读。ω 统一读“欧米伽”，pω 读“位置乘以频率”，q₃ 读“第三个 query”。
- 长小数在主线口播中取约四位，画布保留完整值。停顿用于等待结果出现和留出观察时间。
- 音色相似度、语气自然度、讲解节奏分别试听判断。先完成一段约 45—60 秒、含疑问和推导的样片，再调整全片配音参数。

### 时间轴的制作顺序

1. 给每个语义短句分配固定编号，并记录画面对象、操作和对应触发短语。
2. 生成该段配音，保留实际音频、最终口播文本和字幕时间戳。先检查术语读音与语气。
3. 对齐“位置二”“乘一”“二弧度”等关键短语。句级时间戳可以确定场景区间，句内动作需要进一步做文本与音频对齐或手动标定。
4. 根据短语时间生成鼠标移动、点击、圈线、数值更新和字幕事件。鼠标位置由目标元素当前边界计算，固定录制尺寸与字体后再渲染。
5. 视频每一帧按统一时间轴计算状态。浏览器完成布局、字体加载和数据计算后再采样。生成帧与最终音轨共用时间起点。
6. 检查每个关键事件附近的画面和音频。定位对象、读数、公式展开和切镜逐项核对。某段重配音后，只重新对齐和渲染该段，再累计全片时间。

### 一句话如何拆成动作

示例口播“先看位置二。乘上这一对的频率一，角度就是二弧度。”

| 语音触发短语 | 画面动作 | 安排方式 |
|---|---|---|
| “先看” | 鼠标移向第三个 token 的位置编号 | 利用前一句收尾或本句开头完成移动 |
| “位置二” | 高亮 p=2 | 指针提前约 0.2—0.4 秒到达，按样片调整 |
| “这一对的频率一” | 指向 ω₀=1，高亮维度对 (0,1) | 保留 p=2，保持视觉对应关系 |
| “乘上”所在短句 | 展开 2×1 | 动作在对应短句内完成 |
| “二弧度” | 显示结果 θ=2，并高亮结果 | 结果跟随读数出现 |
| 句末停顿 | 保留算式和结果，指针停稳 | 按计算复杂度留出观察时间 |

示例中的提前量是制作初值。真实秒数以最终配音标定为准。验收同时检查指示动作对应的词句、结果出现时机和阅读时间。

第一课管线已支持分段配音、场景截图、字幕和分段合成。本课需要补充句内事件时间轴、移动指针、渐进圈线以及可逐帧重现的动画状态。这些能力目前处于设计阶段。样片完成后，以实际试听和逐段画面验证同步效果。
