# 1000 元资源预算

下面是全程支出上限的分配，**不是厂商报价，也不是每项都要花完**。已有账号余额和资源如能复用，仍记录实际消耗；购买时按地域、规格、计费方式、活动资格和税费核价。没有按“新人特惠一定可用”安排课程。

| 用途 | 预留上限（人民币） | 使用方式 |
|---|---:|---|
| CPU 应用云主机，含主系统盘 | 300 元 | 第 03 课开始；小实例短时或按月使用，先看预计累计费用 |
| 模型生成、embedding、重排 API | 250 元 | 小问题集、限量调用，复用记录；不以压测为理由大量消耗模型 |
| 对象存储、额外备份 | 60 元 | 小文档集，实验后检查版本、快照和副本 |
| 网络流量及其他网络费用 | 60 元 | 先核对套餐包含项，单独记录超出部分 |
| 短时网络/多实例实验 | 100 元 | 只为验证具体问题开启，不长期保留多套环境 |
| 机动余量 | 230 元 | 失败重跑、价格变化、确有需要的额外实验 |
| **总计** | **1000 元** | 不因还剩预算而追加产品 |

若 CPU 主机报价使预计累计费用超过 300 元，就改为更短租期或按需短时实验；不先购买再补预算。本机完成数据库、向量索引和双实例实验的大部分练习，云上验证部署、网络和恢复。前期不需要 GPU，也不需要把托管数据库、NAT 网关、负载均衡常驻开启。

记录：日期、资源/模型、地域与规格、计费单位、预计使用时长或 token、预计费用、实际账单、释放状态。教学假设费率只能用于练习，不混入实付账。

| 日期 | 资源或模型 | 预计费用 | 实际费用 | 已释放或到期时间 | 备注 |
|---|---|---|---|---|---|
| 待首次实验 | — | — | 未使用 | — | 此表为空记录，不代表已经消费 0 元完成了实验 |

课程的预算分配不会自动约束云账号扣费。上云时设置可用的预算提醒，累计达到 700 元先复查剩余课程，达到 850 元优先使用现有环境与本机；提醒不等于自动停机。

## 下课后怎样停止计费

先保存需要的实验记录与数据，再逐项检查实例、云盘、快照、对象、IP、网络产品和日志存储的状态。只清理本课程新建且不再需要的资源，不动已有业务资源。

关机和删除不是一回事。腾讯云文档说明，满足条件并选择“关机不收费”后，停止的是实例计算资源费用，云盘等组件仍可能继续收费；在实例内部执行关机也不等同于这个选项。具体以当时产品计费规则及账单为准。[官方说明](https://cloud.tencent.com/document/product/213/19918)

模型请求也需要记账：重跑会再发请求，超时不证明服务商没处理。没有 usage 的记录标“未知”，不能填成 0；真实用量和金额以服务商记录核对。
